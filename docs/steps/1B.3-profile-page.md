# Step 1B.3 – Photographer public profile page

Plan reference: `docs/PLAN.md` step 1B.3. Owner: web-developer; seo-auditor glance at metadata and structured data. Blocked by 1B.1 (merged); integration checkpoint 1A.4 (merged). First public content page on the footoo.bas.lu preview.

## Goal

`/{locale}/photographers/{slug}` renders a published photographer's profile, portfolio and products from the real API. It is server-rendered, cached, has correct metadata and structured data, and offers a way to request a quote.

## Decisions for this step

- **Data.**
  - The page is a server component calling `GET /v1/photographers/{slug}` and `GET /v1/photographers/{slug}/products` through `@photoo/api-client`, in parallel.
  - Any API 404 (unknown or unpublished profile) renders `notFound()`. Other API errors throw to `error.tsx`, never a half-rendered page.
  - ISR with `revalidate = 300`. On-demand revalidation when a photographer edits their profile waits for 1B.8.
  - `generateStaticParams` returns an empty list, so pages are generated on first request.
- **Localised text.**
  - `bio`, product `title` and `description` are `LocalizedText`. Pick the route locale, then `en`, then the first available locale.
  - A fallback block gets a `lang` attribute with its real locale.
  - The helper lives in `apps/web/src/lib/localized-text.ts` with tests.
- **Images.**
  - Portfolio, avatar and cover URLs come from the API (`S3_PUBLIC_BASE_URL`). The web app gets `NEXT_PUBLIC_MEDIA_BASE_URL`, which drives `images.remotePatterns` in `next.config.ts` and the CSP `img-src` in `lib/csp.ts`.
  - It is validated in `lib/env.ts` and defaults to nothing, so remote images are blocked unless configured.
  - It is added to `.env.example`, `deploy-preview.yml` build args and the preview compose (`https://footoo.bas.lu/photoo-public`).
  - `next/image` with explicit width and height from the API. The grid is responsive: masonry-like columns, no layout shift.
  - The API only returns approved images, and the page never filters or trusts anything else.
- **Money.**
  - Prices are shown as the API returns them (the client pays the product price; the 5 % fee comes out of the photographer's side, `docs/PAYMENTS.md`).
  - Formatting goes through `Intl.NumberFormat` in the route locale with the money's currency, from integer cents.
  - "From" pricing is the lowest tier price per product.
- **Links.** Profile links render as external anchors with `rel="nofollow ugc noopener noreferrer"` and `target="_blank"`. The contract already limits them to http(s). The visible label is the hostname, never the raw URL.
- **CTA.**
  - "Request a quote" links to `/{locale}/requests/new?photographer={slug}`. Signed-out users go through `sign-in?next=…` (existing `next` sanitising).
  - `requests/new` doesn't exist until 1B.5, so this step adds a minimal placeholder page there ("coming soon" plus a link back) that 1B.5 replaces. The CTA is visible on the preview without a dead link.
  - No contact details are shown. Contact happens through requests and chat (anti-circumvention of the platform fee).
- **Metadata** (`generateMetadata`):
  - title `"{displayName} – {city}"`;
  - description from the headline, or the localised bio truncated to 160 chars;
  - canonical and `alternates.languages` for every supported locale;
  - Open Graph `profile` type.
  - Robots stays governed by `NEXT_PUBLIC_ALLOW_INDEXING` (preview is noindex).
- **OG image.** `opengraph-image.tsx` with `next/og` shows the display name, city, categories and the wordmark, on brand tokens. It uses no remote portfolio image, which avoids fetching user content at OG render time; revisit with the brand kit (0.8).
- **Structured data.**
  - One JSON-LD `<script type="application/ld+json">` with the CSP nonce.
  - Content: a `ProfessionalService` (a `LocalBusiness` subtype) with `name`, `url`, `image`, `address` (city and country only), `areaServed`, `knowsLanguage`, and a `founder` `Person`.
  - `makesOffer` holds one `Offer` per active product tier, each with an `itemOffered` `Service` and `priceSpecification` in currency units.
  - `aggregateRating` only when `ratingCount > 0`.
  - The JSON is serialised with `<`, `>` and `&` escaped as unicode, so user text can't close the script tag.
  - Built in `apps/web/src/lib/profile-jsonld.ts` with tests.
- **Empty states.** No products: the section shows "no packages yet" and the CTA still works. No portfolio: the section is hidden.
- **Sitemap entries** for profiles are 1B.11, not this step.

## Tasks

1. `apps/web/src/app/[locale]/photographers/[slug]/`: `page.tsx`, `opengraph-image.tsx`, `not-found.tsx` (profile-specific copy), and components for header (cover, avatar, name, headline, city, categories, languages, rating), bio, portfolio grid, products with tiers, links and CTA.
2. `apps/web/src/app/[locale]/requests/new/page.tsx` placeholder (protected: redirects to sign-in when signed out).
3. Libs: `localized-text.ts`, `money.ts` (format cents), `profile-jsonld.ts`; env, CSP and `next.config.ts` image host; preview compose, `.env.example` and workflow build arg.
4. i18n: all strings in `packages/i18n/messages/en.json` under `web.profile.*` and `web.requests.placeholder.*`, with category, language and licence usage labels reused if they exist, otherwise added under `common.*`. i18n-maintainer drafts the other locales.
5. Tests (Vitest and Testing Library):
   - localised text fallback order and `lang`;
   - money formatting per locale and currency;
   - JSON-LD shape, no `aggregateRating` at zero ratings, and a script-breaking string escaped;
   - page renders `notFound` on API 404 and throws on 500 (mocked api-client);
   - links get the `rel` attributes;
   - CSP includes the media origin only when set.
   - Web coverage threshold must not drop.
6. Manual check against the local stack with the seeded demo photographer: page renders, images load through MinIO, `curl` shows the JSON-LD and `X-Robots-Tag`, and the Rich Results test is pasted in the PR when the preview is reachable.

## Follow-ups

- The seed must include at least one published photographer with approved portfolio images and products. If not, schema-migrator extends the seed in this step.
- Preview images need `NEXT_PUBLIC_MEDIA_BASE_URL` in the GitHub repository variables (set by Claude through `gh`, no human action).
