# Step 1B.1 – Web app shell

Plan reference: `docs/PLAN.md` step 1B.1. Owner: web-developer. Branch: `feat/1B.1-web-shell`. Blocked by 0.10 and 0.11 (both merged).

## Goal

`apps/web` becomes a running Next.js App Router app with locale routing for en/fr/de/pt/es, Tailwind + shadcn/ui on neutral design tokens, base layout, navigation, footer, error pages, security headers, and a typed API client pointed at the mock server.

## Workarounds for missing human input

- Brand kit (O5, step 0.8) is not available: define design tokens as CSS variables in one file (`src/styles/tokens.css`) with a neutral palette and system font stack, so the brand swap is a single-file change. Logo is a text wordmark component. Tracked in `docs/steps/human-followups.md`.
- Sentry DSN (0.6) does not exist yet: wire `@sentry/nextjs` so it is a no-op when `SENTRY_DSN` is unset, and fail the production build if it is unset with `NODE_ENV=production` and `SENTRY_REQUIRED=true` (set in the staging/prod environment later).

## Tasks

1. Replace the placeholder library build with Next.js (latest 16.x), React 19, exact versions. Scripts: `dev` (port 3000), `build` (`next build`), `start`, `lint`, `typecheck`, `test`. Turbo outputs `.next/**` excluding cache. Keep ESLint on the shared config plus the Next plugin.
2. next-intl: locales and default from `@photoo/shared` (`SUPPORTED_LOCALES`, `DEFAULT_LOCALE`), messages via `getMessages` from `@photoo/i18n`, middleware/proxy that redirects `/` using `resolveLocale` on `Accept-Language`, always-prefixed routes `/[locale]/…`, `<html lang>` set, `hreflang` alternates in root metadata.
3. Tailwind 4 + shadcn/ui initialised (components copied into `src/components/ui`, only those used: button, dropdown-menu, sheet for mobile nav). Tokens from `tokens.css`, dark mode via `prefers-color-scheme`.
4. Layout: header (wordmark, nav links to placeholder pages "Find a photographer", "For photographers", "Jobs", locale switcher, sign-in link), footer (legal link placeholders: imprint, privacy, terms, cookies), skip link, responsive mobile nav.
5. Pages: localized home with a hero and search placeholder, `not-found`, `error` (client boundary with retry), global error. All strings in `packages/i18n/messages/en.json` under `web.*` namespaces; `pnpm i18n:check` stays green.
6. API client: `src/lib/api.ts` creates `createApiClient` from `@photoo/api-client` with `NEXT_PUBLIC_API_URL`, validated with zod at startup (fail loudly with the variable name). `.env.example` points at the mock `http://127.0.0.1:4010`.
7. Security headers per `docs/SECURITY.md` web section via `next.config` headers: CSP with nonces (script-src 'self' 'nonce-…', no unsafe-inline for scripts), `frame-ancestors 'none'`, HSTS with preload (production only), `Cross-Origin-Opener-Policy same-origin`, `Referrer-Policy strict-origin-when-cross-origin`, `Permissions-Policy` minimal, `X-Content-Type-Options nosniff`. GTM origins are added later in 1B.10.
8. Tests: Vitest + Testing Library for the locale switcher and header nav; unit test for the locale redirect logic; a build smoke check in CI (`pnpm build` already runs). Playwright comes in 1B.12.
9. Verify `pnpm --filter @photoo/web dev` renders `/en` and `/fr` against the mock, and `/` redirects per `Accept-Language`.
10. Update `CLAUDE.md` Commands (`pnpm --filter @photoo/web dev`) and `docs/steps/human-followups.md` (brand tokens file, Sentry env).

## Out of scope

Auth screens (1B.2), consent banner and GTM (1B.10), SEO pass (1B.11), real content.

## Done when

- All root checks + audit green, CI green, PR merged
- Dev server renders all five locales; security headers present (checked with curl)
