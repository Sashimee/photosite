# Step 0.3 – Local dev stack

Plan reference: `docs/PLAN.md` step 0.3. Owner: devops-engineer. Branch: `chore/0.3-dev-stack`.

## Goal

One command brings up the backing services every app needs locally: PostgreSQL 16 with PostGIS, Redis 7, MinIO (S3-compatible) and Mailpit. Each app documents its environment in a committed `.env.example`.

## Tasks

1. `infra/docker/compose.dev.yml` with services, all ports bound to `127.0.0.1` only:
   - `postgres`: `postgis/postgis:16-3.5` image, named volume, healthcheck (`pg_isready`), dev database `photoo` and a separate `photoo_test` database created by an init script under `infra/docker/postgres/` that also enables the `postgis` extension.
   - `redis`: `redis:7-alpine`, healthcheck (`redis-cli ping`).
   - `minio`: pinned tag, API + console ports, named volume, healthcheck; one-shot `minio-init` (`minio/mc`) that creates the buckets `photoo-private` (verification docs, chat attachments, originals) and `photoo-public` (public variants) with no anonymous access.
   - `mailpit`: pinned tag, SMTP + web UI ports.
   - Image tags pinned to exact versions; credentials read from a root `.env` with dev-only defaults in `infra/docker/.env.example`.
2. Root scripts: `pnpm stack:up` (`docker compose -f infra/docker/compose.dev.yml up -d --wait`), `pnpm stack:down`, `pnpm stack:reset` (down with volumes).
3. `.env.example` for `apps/api`, `apps/worker`, `apps/web`, `apps/admin`, `apps/mobile`, `packages/db` with the variables each needs to reach the stack (`DATABASE_URL`, `REDIS_URL`, `S3_*`, `SMTP_*`, public API URL). Values are local dev defaults only, never real secrets. Un-ignore `.env.example` in `.gitignore` (currently swallowed by `.env.*`).
4. Seed entry point: `packages/db` gets a `seed` script placeholder wired to `src/seed.ts` that exits cleanly; real seed data lands in 0.9. Root `pnpm db:seed` forwards to it.
5. Verify locally: `pnpm stack:up` reaches healthy state, `psql` can `SELECT postgis_version()`, buckets exist, Mailpit UI answers; then `pnpm stack:down`.
6. Document the commands in `CLAUDE.md` Commands and `README.md`.

## Out of scope

`pnpm dev` running the apps themselves (apps are still empty shells), production Dockerfiles (0.5), Prisma schema (0.9), CI service containers (1E.4).

## Environment workaround

The host has Docker 29 without the compose plugin. Install the pinned `docker-compose` CLI plugin binary into `~/.docker/cli-plugins/` for this machine (user-local, no sudo); note it in `README.md` prerequisites.

## Done when

- Stack comes up healthy locally and PostGIS query succeeds
- `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm format:check` green
- PR into `dev` opened (not merged, per global git rules)
