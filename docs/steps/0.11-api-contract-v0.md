## 0.11a tasks

1. `packages/shared` dependencies (exact versions, check `minimumReleaseAge`): `zod` 4.x, `@asteasolutions/zod-to-openapi` 9.x.
2. Primitives in `packages/shared/src/contract/common.ts`: `Id` (uuid), `IsoDateTime`, `CurrencyCode` (ISO 4217, 3 upper-case letters), `Money` (`amountCents` integer >= 0 + `currency`), `LocaleSchema` built from `SUPPORTED_LOCALES`, cursor pagination (`cursor`, `limit` 1..100 default 20 -> `{ items, nextCursor }`), `ApiError` (`code`, `message`, `details?`, `requestId`) with standard error responses 400/401/403/404/409/422/429. All objects `.strict()` (SECURITY.md: unknown keys rejected).
3. Enums in `packages/shared/src/enums.ts` mirroring `docs/DATA-MODEL.md` for the entities this sub-step touches: `UserRole`, `UserStatus`.
4. Fee helper `packages/shared/src/fee.ts`: `calculatePlatformFee(subtotalCents, feePercent)` = `Math.round(subtotalCents * feePercent / 100)` per DATA-MODEL invariant; rejects non-integer or negative cents and fee outside 0..100 with a thrown `RangeError`; `quoteTotals(lineItems, feePercent)` returning `{ subtotalCents, platformFeeCents, totalCents }`. Tests for rounding at .5, zero, large values, invalid input. Whether the fee is added on top of the subtotal or deducted from the photographer payout is defined in `docs/PAYMENTS.md`; follow it, and stop and report if it is ambiguous.
5. Registry `packages/shared/src/contract/registry.ts` exporting an `OpenAPIRegistry`, `/v1` prefix, security schemes `cookieAuth` (web) and `bearerAuth` (mobile).
6. Auth resource `packages/shared/src/contract/auth.ts`, per PLAN 1A.2: sign-up (email, password min 10 per SECURITY.md, roles subset of client/photographer/professional, locale), sign-in, sign-out, session (current user), verify email, request/confirm password reset, add role, TOTP enroll/verify/disable. Request and response schemas plus registered paths with error responses. No OAuth callback internals (auth library owns them), just the redirect start endpoint per provider (google, apple, facebook, microsoft).
7. Generation: `packages/shared` script `openapi:generate` writes `packages/api-client/openapi.json` (committed, OpenAPI 3.1, info version `0.1.0`). A test fails when the committed file is stale.
8. `packages/api-client`: `openapi-typescript` generates `src/schema.d.ts` (committed per ARCHITECTURE "regenerated in CI and committed"), `src/index.ts` exports `createApiClient({ baseUrl, fetch? })` built on `openapi-fetch`. Script `generate`. CI step fails if regenerating produces a diff.
9. Mock: root `pnpm mock:api` runs the pinned Prism Docker image (keeps its vulnerable transitive deps out of the lockfile) against `packages/api-client/openapi.json` on `127.0.0.1:4010` with dynamic examples. Add examples to schemas where Prism would otherwise produce nonsense (emails, ids).
10. Tests: schema edge cases (strict unknown key rejection, password length, invalid role, pagination limits), fee helper, stale-openapi test, a client typecheck test (a typed call compiles, a wrong body is a `@ts-expect-error`).
11. Docs: `CLAUDE.md` Commands (`mock:api`, `openapi:generate`, api-client `generate`), README contract section short.

## Out of scope

NestJS wiring (1A.2 and later), resources in 0.11b/0.11c, real auth behaviour.
