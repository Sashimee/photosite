# Step 0.1 – Monorepo scaffold

Plan reference: `docs/PLAN.md` step 0.1. Owner: main session. Branch: `chore/0.1-monorepo-scaffold`.

## Goal

A pnpm + Turborepo workspace where `pnpm lint`, `pnpm typecheck`, `pnpm test` and `pnpm build` run green across every workspace, with the layout from `docs/ARCHITECTURE.md`.

## Tooling versions

- Node 24 (`.nvmrc`, `engines`), pnpm 12 (`packageManager`)
- Turborepo 2, TypeScript 6.0 (typescript-eslint does not support TS 7 yet), ESLint 9 flat config + typescript-eslint 8, Prettier 3, Vitest 5, husky 9 + lint-staged 17

## Tasks

1. Root: `package.json` (scripts `dev`, `lint`, `typecheck`, `test`, `build`, `format`, `prepare`), `pnpm-workspace.yaml` (`apps/*`, `packages/*`), `turbo.json`, `.nvmrc`, `.prettierrc.json`, `.prettierignore`, `.editorconfig`, `.gitignore` additions (`.turbo`, `coverage`, `.next`, `.expo`).
2. `packages/config`: `tsconfig/base.json` (strict, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, NodeNext), `tsconfig/library.json`, `eslint/base.js` (typescript-eslint strict type-checked + prettier compat), exported via `package.json` `exports`.
3. Workspaces `apps/{web,admin,mobile,api,worker}` and `packages/{db,shared,api-client,i18n}`: `package.json` named `@photoo/<name>`, `tsconfig.json` extending the base, `eslint.config.js`, `src/index.ts` placeholder, scripts `lint`, `typecheck`, `test` (`vitest run --passWithNoTests`), `build` (`tsc`). Frameworks (Next.js, Expo, NestJS, Prisma) are installed by their own steps (1B.1, 1C.1, 1D.1, 1A.x, 0.9).
4. husky `pre-commit` running lint-staged (prettier + eslint on staged files).
5. `CLAUDE.md` Commands section and `README.md` setup section updated to the real scripts.

## Out of scope

CI (0.2), compose stack (0.3), Prisma (0.9), i18n catalogs (0.10), `pnpm i18n:check` and `pnpm mock:api` (0.10, 0.11).

## Done when

- `pnpm install` clean from a fresh clone
- `pnpm lint && pnpm typecheck && pnpm test && pnpm build` green
- PR into `dev` merged
