# Step 0.2 – CI

Plan reference: `docs/PLAN.md` step 0.2. Owner: devops-engineer. Branch: `chore/0.2-ci`.

## Goal

Every PR into `dev` or `main` (and every push to them) runs format check, lint, typecheck, tests, build and a dependency audit on GitHub Actions; Dependabot keeps npm dependencies and actions current.

## Tasks

1. `.github/workflows/ci.yml`: one `checks` job on `ubuntu-latest`, Node from `.nvmrc`, pnpm from `packageManager`, pnpm store cache, `pnpm install --frozen-lockfile`, then `format:check`, `lint`, `typecheck`, `test`, `build`, `pnpm audit --audit-level high` (`docs/SECURITY.md`). Actions pinned by commit SHA, `permissions: contents: read`, concurrency cancels superseded runs, 15 minute timeout.
2. `.github/dependabot.yml`: weekly npm updates targeting `dev`, grouped minor/patch; weekly github-actions updates.
3. Verify on the PR itself that the workflow runs green.

## Out of scope

Turborepo remote cache (optional, needs a token – revisit when builds get slow), Postgres service for integration tests (1E.4), Lighthouse CI (1B.11), image build and deploy (0.5).

## Done when

- CI run on the PR is green
- PR merged into `dev`
